The arithmetic check verifies arithmetic only. It does not validate an input,
confirm a bibliographic identity, or verify that a cited source supports an
attributed claim. Citation keys in the assessment must therefore be treated as
provisional until checked against the primary sources from an environment that
can retrieve them.
